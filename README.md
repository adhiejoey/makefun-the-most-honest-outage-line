One status-page line, at most 160 characters, written in the voice of an AI agent reporting a total server outage: it names what is down, admits that its own checking dashboard is down too, and refuses to invent a cause or an ETA, because the most honest thing an agent can say while everything is dark is that it cannot verify anything right now. Running `node main.ts` writes that single line to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).
